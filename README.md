# Projeto Android — Curso em Vídeo

Projeto desenvolvido durante o **Capítulo 17 do curso de HTML5 e CSS3** do canal **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

## 📱 Sobre o projeto

O projeto consiste na criação de uma página web sobre a história do **sistema operacional Android**, utilizando os conhecimentos de HTML5 e CSS3 adquiridos durante o curso.

A página apresenta informações sobre a origem do Android, sua evolução e algumas de suas principais características, além de utilizar diferentes recursos de estruturação e estilização de páginas web.

## 💻 Tecnologias utilizadas

* **HTML5**
* **CSS3**

## 📚 Conceitos praticados

Durante o desenvolvimento do projeto, foram praticados conceitos como:

* Estrutura semântica do HTML5
* Utilização de títulos e parágrafos
* Inserção de imagens
* Links
* Listas
* Formatação de textos
* Cores e fontes
* CSS externo
* Seletores CSS
* Bordas e sombras
* Responsividade
* Media Queries
* Organização e estilização de uma página web

## 🎯 Objetivo

O objetivo deste projeto foi colocar em prática os conhecimentos de **HTML5 e CSS3** apresentados ao longo do curso, desenvolvendo uma página web completa e responsiva.
